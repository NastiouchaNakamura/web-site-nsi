# Productions d'élèves

Vous trouverez ici une présentation de quelques productions d'élèves du lycée
Blaise Pascal, en SNT ou en NSI.

!!! example "Catégories"
    === "Sites Web (SNT)"
        Quelques **sites Web**, réalisés par les élèves de 2<sup>nde</sup>, en cours
        de **SNT**, sont accessibles via le lien ci-dessous.
        
        [Accéder aux sites Web](snt_web.md)
    === "Projets Python (NSI)"
        Les **projets de programmation Python** sont réalisés dans le cadre de
        l'enseignement de la **NSI**, en classe de **1<sup>ère</sup>** ou de
        **T<sup>ale</sup>**.

        [Accéder aux projets Python](nsi_projets.md)
